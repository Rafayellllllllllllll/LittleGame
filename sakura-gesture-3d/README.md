# 樱花手势 · 3D 互动网页

基于摄像头手势识别的 3D 樱花互动网页，单文件 `index.html`，可直接部署到 GitHub Pages。

## 画面

- 一棵大小错落的樱花树：大花在前、小花在后，层次分明
- 配色以粉色为主，点缀白色、淡紫、杏色、浅金色
- 绿色叶片穿插在枝叶与花朵之间，另有树干与分枝
- 飘落的花瓣、金色花蕊、白色与金色闪烁光点、柔和背景光晕
- 放大后细节逐级增加，见下方 LOD 说明

## 手势操作（需要前置摄像头）

| 手势 | 效果 |
|---|---|
| 双手同时张开 | 画面整体放大 |
| 双手同时合拢 / 握拳 | 画面整体缩小 |
| 单手左右挥动 | 画面跟随手的方向左右旋转，松手后带平滑惯性滑一小段再停下 |
| 单手不动 / 只有一只手 | 只旋转，不缩放（缩放只认双手） |

判断方式：MediaPipe Hands 检测双手 21 个关键点，用手掌大小归一化指尖距离判断张开 / 握拳；连续 3 帧同一手势才触发缩放，避免抖动；缩放与旋转都用插值 + 惯性衰减平滑过渡。

手势识别用的是前置摄像头画面，左右方向已做镜像处理：你向右挥，画面就向右转。

## LOD（放大逐级加细节）

| 缩放 | 等级 | 细节 |
|---|---|---|
| 小于 100% | LOD 0 简约 | 只显示花瓣与叶片主体 |
| 100%–155% | LOD 1 标准 | 大花的金色花蕊出现，花苞出现 |
| 155%–200% | LOD 2 精细 | 全部花蕊、内层小花瓣、叶片叶脉出现 |
| 200% 以上 | LOD 3 极致细节 | 同 LOD 2 的完整细节，配合更近的视角观看 |

页面左下角会实时显示当前缩放百分比与 LOD 等级。

## 没有摄像头时的备用操作

- 拖动：左右 / 上下旋转视角
- 滚轮：缩放
- 双指捏合：缩放（手机）
- 点右下“演示模式”：自动呼吸式缩放 + 缓慢旋转，不用摄像头也能看到 LOD 变化
- 点“重置视角”回到初始视角；点“隐藏面板”可全屏看花，右上角 🌸 按钮恢复面板

## 自适应

- 手机端自动降低花朵数量、飘落花瓣与光点数量，并限制渲染像素比，兼顾流畅度
- 横屏与竖屏自动调整相机距离：竖屏离得更远，保证整棵树完整入画
- 桌面端花朵约 178 朵、飘落花瓣约 220 片、光点约 1270 个；手机端分别约为 96 朵、90 片、500 个

## 本地运行

摄像头只能在安全环境（https 或 localhost）下使用，直接双击打开 `file://` 会被浏览器拒绝摄像头。

```bash
cd sakura-gesture-3d
python3 -m http.server 8000
```

然后用浏览器打开 `http://localhost:8000/`，点“开启摄像头”并允许权限。

## 部署到 GitHub Pages

仓库根目录就是网站根目录，不需要构建步骤：

1. 新建一个公开仓库，例如 `sakura-gesture-3d`，把 `index.html` 和 `README.md` 推到 `main` 分支根目录。
2. 打开仓库 Settings → Pages → Build and deployment → Source 选择 Deploy from a branch。
3. Branch 选择 `main`，Folder 选择 `/ (root)`，保存。
4. 等 1–2 分钟后访问 `https://<你的用户名>.github.io/sakura-gesture-3d/`。
5. 必须用这个 https 地址打开，摄像头才能申请权限；用 http 或 `file://` 打开时摄像头会被浏览器拦截，页面仍可用拖动 / 滚轮 / 双指操作。

## 常见问题

- 点“开启摄像头”没反应：先确认用的是 https 的 Pages 地址，且浏览器地址栏已允许摄像头；部分手机浏览器需要在系统设置里先给浏览器摄像头权限。
- 手势不灵敏：把双手都放进画面、光线亮一点、手离摄像头 40–80 厘米；张开要五指分开，握拳要手指收紧。
- 画面卡顿：手机端已自动降质；仍卡可缩小浏览器窗口或关闭其他占用摄像头的应用。
- 页面打不开手势库：Three.js 与 MediaPipe Hands 都走 CDN，需要能访问互联网。

## 技术栈

- Three.js（CDN，ES Module）：樱花树、花瓣、叶片、花蕊、飘落花瓣、光点
- MediaPipe Hands（CDN）：双手 21 关键点检测，`maxNumHands: 2`
- 原生 HTML / CSS / JavaScript，无构建步骤
