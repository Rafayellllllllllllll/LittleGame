# 微粒沙盘 · Powder Box

落沙类物理沙盘：**200×120 网格**，每格一个粒子，沙、水、油、火、蒸汽、植物、酸、岩浆互相反应。拖动就画，能量守恒、水位会自己摊平、火会烧掉木头产生烟、岩浆遇水凝成石头、酸会腐蚀石头。

纯前端 Canvas 2D，**零依赖、零构建**。

## 怎么跑

ES Module 需要 HTTP：

```bash
python -m http.server 8790
# 或 npx serve -l 8790
```

打开 <http://localhost:8790/>。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 拖动 | 用当前元素绘制 |
| 右键 | 擦拭 |
| `1`–`9` / `0` | 选元素 / 橡皮 |
| `[` `]` | 笔刷 1–14 |
| `空格` | 暂停 |
| `N` | 单步 |
| `C` | 清空 |

四个预设：**沙漏**（纯重力）、**火山**（岩浆 + 木）、**雨林**（水 + 草，会自己蔓延）、**酸池**（酸腐蚀石柱）。

## 元素与规则

| 元素 | 行为 |
| --- | --- |
| 沙 | 下落、逐格堆成锥形；能沉进液体 |
| 水 | 下落 + 横向摊平，形成水位；浇灭火产生蒸汽 |
| 油 | 比水轻，会浮在水面；可燃 |
| 火 | 寿命有限，向上窜，点燃相邻的木/油/草，熄灭后可能留烟 |
| 烟 | 上升、寿命到就消散 |
| 汽 | 上升，冷凝回水（所以水是守恒的） |
| 草 | 只要挨着水就以一定概率把水转成草并向上蔓延 |
| 酸 | 像液体一样流动，腐蚀石/木/沙，自身按概率被消耗 |
| 岩浆 | 黏稠（只有 1/3 概率更新），遇水凝固成石并把水变成蒸汽，点燃可燃物 |
| 石 / 木 | 静止；木可燃，石可被酸腐蚀 |

密度决定浮沉：`油 2 < 水 3 < 酸 3.2 < 岩浆 5`，所以沙会沉底、油会浮上来。

## 实现要点

- **单缓冲 + 自底向上扫描**：每个粒子每帧最多移动一格，落入已扫描过的格子，避免同一粒子在一帧内被移动多次。
- **交替扫描方向**：每帧翻转水平方向（`g.flip`），否则液体会持续偏向一侧，形成假的"水流"。
- **类型化数组**：`Uint8Array` 存元素与寿命，200×120 = 24000 格，整体内存 48KB。
- **渲染**：画布内部就是 200×120 像素（1 格 = 1 像素），用 CSS 放大并 `image-rendering: pixelated`，所以**和 DPR 无关、永远锐利**，也不会有 24k 次 fillRect 的开销。
- **调色板噪声**：每格用整数哈希做 ±9% 明度扰动，避免大片纯色；水面只在"上方有空气"时提亮，形成反光；火焰颜色按剩余寿命在暗红→亮黄间插值。
- **确定性**：所有随机性都通过传入的 `rand` 函数，`mulberry(seed)` 可复现整场模拟——测试就是靠这个做哈希比对。

## 测试

模拟内核不碰 DOM，所以能直接在 node 里跑：

```bash
npm test          # 内核 23 项 + 接线 30 项
npm run test:sim  # 只跑物理
npm run test:wiring
```

**内核 23 项**覆盖：

- 沙：单粒落底、数量守恒、堆成锥形且不穿透地板
- 水：数量守恒、水位摊平（扩散列数变多、最高水柱下降）
- 油水分离：油的平均高度必须高于水
- 石：哈希不变（完全静止）
- 火：烧掉木头、最终熄灭；遇水生成蒸汽并熄火；蒸汽 500 帧后**全部冷凝回水且水量守恒**
- 烟：上升并消散
- 反应：岩浆遇水 → 石头 + 蒸汽 + 水减少；酸腐蚀石头且自身减少；草消耗水生长
- 健壮性：全元素混战 300 帧无非法值、空网格不凭空造粒子、同种子同结果、tick 递增
- 性能：200×120 跑 300 帧 **约 1.2 秒（≈250fps）**

**接线 30 项**（因为本机无法跑无头浏览器，把会炸的地方静态查掉）：
DOM id 是否存在、`main.js` 导入的 11 个符号是否真的导出、资源路径、11 个元素是否都有名字与颜色、13 个功能点在改动后是否还在、4 个预设能否跑通。
