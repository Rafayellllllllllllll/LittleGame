# 午夜失物招领处 · 第一章：没有名字的来访者

可实际游玩的网页解谜游戏，竖屏手机优先，桌面端同样可用。

## 直接玩

- 单文件版：`dist/midnight-lost-found.html`，用浏览器直接打开就能玩，不需要服务器。
- 模块源码版：用任意静态服务器打开根目录，例如 `python3 -m http.server 8000`，再访问 `index.html`。

## 结构（组件化，不是单文件堆砌）

- `index.html`：首页 / 游戏主界面 / 结局 / 弹窗骨架
- `css/style.css`：深海蓝 + 墨黑 + 旧纸白 + 暖金视觉，雨滴、雾气、悬浮、转场
- `js/config.js`：部署配置，只放 anon 公开密钥占位，不放服务端密钥
- `js/state.js`：游戏状态模型 + 本地存档（localStorage）+ 导出/导入
- `js/data.js`：线索、道具、8 个谜题、对话树、结局、成就
- `js/puzzles.js`：谜题引擎（选择 / 时钟 / 旋转 / 排序 / 配对 / 组合 / 最终推理）
- `js/board.js`：线索档案推理板（点选 + 拖拽 + 撤销）
- `js/dialogue.js`：NPC 对话、信任度、出示证据、最终选择与 3 个结局
- `js/audio.js`：WebAudio 合成音效与雨声，不依赖外部音频
- `js/ui.js`：场景调查、背包、线索、谜题列表、设置
- `js/supabase.js`：可选云同步，失败时降级本地存档
- `js/main.js`：启动、雨滴画布、标签页、存档操作接线
- `supabase/schema.sql`：新项目专用表 + 索引 + RLS（每人只能读写自己的行）

## 真相推导链（答案全部可查，不是猜密码）

1. 录音 23:03 已有来访者的声音，他却说 23:20 才第一次来 → 谜题 1。
2. 钟面 23:24，记录本说钟慢 7 分钟 → 真实停表时间 23:31 → 谜题 2，暗格里是旧照片。
3. 雨衣背面 + 转 180°，内袋新针脚 → 谜题 3。
4. 残信按语义排序：妈妈把黄铜钥匙缝进了旧雨衣的内袋 → 谜题 4。
5. 照片三人：沈伯 / 妈妈阿棠 / 小男孩沈默 → 谜题 5。
6. “从没来过”被录音带（或照片）反驳 → 谜题 6。
7. 雨衣 + 剪刀拆线，取出黄铜钥匙 → 谜题 7。
8. 最终推理：沈默 / 黄铜钥匙 / 旧雨衣内袋 → 谜题 8。

## 结局分支（状态真的会变，不只是换文字）

- 真结局「记起名字的雨夜」：解开谜题 8，且对话里出示过那封信、信任 ≥ 50，再选“说出名字递钥匙”。
- 体贴结局「没有说破的体贴」：解开谜题 8 后选“把钥匙放在柜台上”。
- 悬念结局「雨还没有停」：解开谜题 8 后选“先问缝雨衣的晚上”。
- 隐藏物品：拼好信后，柜台暗格里有 2016 年冬的旧车票（写着“沈默”）。
- 成就 12 个，含全线索、零提示通关；每道谜题有三级提示，看过的提示会被记下来。

## 存档与后端

- 默认完整本地存档：每次状态变化自动保存，刷新后点“继续游戏”恢复；设置里可导出/导入 JSON 备份、清除存档。
- Supabase 是可选的、目前是预留接口：先在全新项目里跑 `supabase/schema.sql`，再把项目地址和 anon 公开密钥填进 `js/config.js`（单文件版里搜 `GAME_CONFIG`）。没填、或后端不可用时，游戏会明确提示“云端不可用，已用本地存档继续”，不会卡住、不会丢进度。注意：表结构按“登录用户只能读写自己的行”设计，正式云同步还需要在接入 Supabase Auth 登录后再启用，不要在未登录状态下指望 anon 直接写库。
- 注意：这个新项目不复用错题本的仓库和后端；不要把这份 SQL 跑进错题本的项目。
