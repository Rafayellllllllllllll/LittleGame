# 深海观测站 · Abyssal Observatory

一个程序化生成的深海场景：荧光浮游生物顺着流场漂、水母缓慢上浮并脉动、海雪下沉、光柱从天顶斜切下来，配上缓慢加深的深度读数和一层胶片颗粒。

**没有素材、没有依赖、没有构建**——全部是 Canvas 2D 现算的。

## 怎么跑

ES Module 需要 HTTP（`file://` 打开会报 CORS）：

```bash
python -m http.server 8789
# 或
npx serve -l 8789
```

然后打开 <http://localhost:8789/>。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖动 / 按住 | 在指针处制造水流，把浮游生物推开 |
| 点击 | 撒出一把荧光（带初速与重力） |
| `M` | 开/关深海低频声（WebAudio 现场合成，无音频文件） |
| `空格` | 暂停 |
| `H` | 收起 HUD |
| `G` | 显示 FPS |

URL 参数：`?seed=123` 换一颗星球、`?plankton=800` 加密度、`?debug=1` 直接开 FPS。

## 这一版为什么不是"随手糊的"

代码分成两层，**模拟层完全不碰 DOM**，因此可以在 node 里跑真实测试：

```
core.js         纯函数：值噪声 / 分形噪声 / 流场 / 粒子积分 / 边界回收 / 统计
scene.js        渲染与交互：图层、加色发光、水母伞体、颗粒、音频
test/
  core.test.mjs 14 项模拟测试（确定性、值域、NaN、边界、方向、单调性）
  verify.mjs    静态接线校验（DOM id、import 名、资源路径、功能点）
```

跑一遍：

```bash
npm test        # = core.test.mjs + verify.mjs
```

当前状态：**14 项模拟测试 + 24 项接线/功能校验全部通过**。

### 几个实现细节

- **确定性噪声**：`hash2` 用整数位运算做格点哈希，`noise2` 做 smoothstep 插值，`fbm2` 叠三层。同种子必定生成同一个场景，方便复现与截图。
- **流场**：角度来自 `fbm2` 再叠时间项，强度也由噪声调制，所以既有大尺度涡旋也有细碎扰动；整体加了一点点向上涌流，符合深海观感。
- **视差**：每颗粒子带 `z`（0 远 → 1 近）。远处的受流场影响小、画得暗而小；近处的又快又亮。
- **加色混合**：所有发光都用 `globalCompositeOperation = 'lighter'`，辉光是 `createRadialGradient` 的三段色标（亮核 → 半透明 → 全透明），不用阴影模糊（`shadowBlur` 在移动端很贵）。
- **水母**：伞体是一个椭圆的半圆 + 两段二次贝塞尔的伞缘，脉动靠 `sin(phase)` 同时改 `rx` 与 `ry`（体积感更真）；触手是逐帧重算的控制点，随脉动摆动；体内三个"生殖腺"亮点用径向渐变。
- **胶片颗粒**：96×96 的随机灰度贴图做成 pattern，每帧随机平移后以 `globalAlpha` 叠加——比逐像素噪声便宜两个数量级。
- **性能**：DPR 上限 2；粒子数按屏幕面积缩放；`prefers-reduced-motion` 时整体速度乘 0.45。
